# 🎨 唐卡修复工具

基于 OpenCV 图像处理技术的唐卡数字化修复工具，提供交互式 Web 界面，适用于受损唐卡（及其他传统绘画）的数字化保护与修复。

## 功能特性

| 功能模块 | 说明 |
|---------|------|
| **一键智能修复** | 综合流水线，自动执行裂痕修复、去噪、颜色恢复、锐化等步骤 |
| **裂痕修复** | 基于形态学与边缘检测自动识别裂痕，使用 Telea / Navier-Stokes 算法修复 |
| **手动区域修复** | 画笔标记损坏区域，定向修复 |
| **颜色恢复** | 饱和度增强、暖色调调整、自动白平衡、金色光泽增强 |
| **去噪平滑** | 非局部均值去噪、双边滤波 |
| **对比度调整** | 手动 / 自动对比度、CLAHE 自适应直方图均衡 |
| **锐化增强** | Unsharp Mask 锐化、细节增强 |
| **去污渍** | 深色污渍（墨渍/霉斑）去除、泛黄污渍去除 |

## 快速开始

### 1. 安装依赖

```bash
cd thangka_restoration
pip install -r requirements.txt
```

### 2. 启动应用

```bash
python app.py
```

启动后浏览器访问 `http://localhost:7860` 即可使用。

## 使用方法

### 一键智能修复

1. 上传唐卡图片
2. 勾选需要执行的修复步骤（默认已开启裂痕修复、去噪、颜色恢复、自动对比度、锐化）
3. 调整各项参数（可使用默认值）
4. 点击「开始一键修复」

### 裂痕修复

1. 上传图片
2. 调整「检测灵敏度」（数值越大，检测越多的裂痕）
3. 点击「检测裂痕」预览裂痕位置（红色标记）
4. 调整「修复半径」和算法后，点击「修复裂痕」

### 手动区域修复

1. 上传图片到编辑器
2. 使用画笔工具涂抹需要修复的区域
3. 点击「修复标记区域」

### 颜色恢复

- **饱和度恢复**：增加褪色唐卡的色彩饱和度
- **暖色调调整**：调整色温使颜色更暖
- **自动白平衡**：校正偏色
- **金色增强**：专门增强唐卡中金色/黄色区域的光泽

## 技术原理

- **裂痕检测**：CLAHE 增强 → Canny 边缘检测 → 形态学操作（闭合 + 膨胀）→ 生成掩膜
- **图像修复**：OpenCV `inpaint` — Fast Marching Method (Telea) 或 Navier-Stokes 方程
- **颜色恢复**：HSV 空间饱和度/色调调整 + 灰度世界白平衡
- **去噪**：Non-local Means Denoising / Bilateral Filter
- **对比度**：直方图裁剪拉伸 / CLAHE 自适应均衡
- **锐化**：Unsharp Mask / `detailEnhance`
